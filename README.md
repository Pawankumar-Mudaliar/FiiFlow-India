# TradeSentinel

FIIFlow India, a full-stack financial analytics platform for tracking real-time Foreign Institutional 
Investor (FII) equity flows and sector allocations. Built with React (Vite), Node.js, Express, PostgreSQL, Python and 
Recharts. Features include automated daily regulatory data extraction via Python cron jobs, interactive sector 
mapping heatmaps, a dynamic user-specific watchlist for tracking custom targets, secure authentication, and 
optimized cloud deployment on Vercel and Render.
